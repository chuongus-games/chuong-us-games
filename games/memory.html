🧠 Neon Memory

Memorize the sequence — then repeat it in order

Watch the sequence, then the 4 pads swap positions before your turn, remember each step by COLOR, not by where it was. The sequence grows every round and plays FASTER each time. One wrong note ends the round.

Neon Memory starts friendly. Watch a color sequence, repeat it back. Then the pads start swapping positions before your turn, killing any spatial shortcut, so only real color memory keeps you alive. One slip and the run's over, and it's free to try as many times as you want.
